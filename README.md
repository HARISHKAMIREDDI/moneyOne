# MONEYPLUS Associates Vizag

A polished, single-page financial services landing page for MONEYPLUS Associates Vizag. The site presents loan and insurance advisory services with a premium dark UI, clear calls to action, and a responsive layout designed for desktop and mobile visitors.

## Overview

This project is a static frontend built with semantic HTML and custom CSS. It is structured as a modern business landing page for financial advisory, highlighting:

- Personal loan services
- Business loan services
- Home loan services
- Health and life insurance guidance
- A callback request form for lead capture
- Branch contact details, business hours, and legal links in the footer

## Features

- Responsive one-page layout with sticky navigation
- Hero section with service positioning and trust metrics
- Callback request form for quick lead generation
- Service cards with highlighted rates and benefits
- Insurance section for family protection and policy guidance
- Footer with office address, contact numbers, and business hours
- Floating chat-style support button for improved engagement
- Modern visual treatment using dark themes, gradients, glassmorphism, and smooth hover states

## Tech Stack

- HTML5
- CSS3
- Google Fonts: Inter and Outfit
- Inline SVG icons

## How to Run

This project does not require a build step or package installation.

1. Open the folder in VS Code or File Explorer.
2. Open `index.html` in your browser.
3. Optionally use VS Code Live Server for a smoother local preview.

## Customization Guide

- Update the business name, address, and contact numbers in `index.html`.
- Adjust loan rates, service descriptions, and feature bullets to match the latest offerings.
- Modify colors, spacing, or typography in `styles.css` to match your brand.
- Replace placeholder form behavior with backend submission logic if callback collection is required.

## Notes

- The callback form is currently frontend-only and uses `onsubmit="return false;"`.
- The chat button is a visual engagement element and does not connect to a live support system yet.
- The legal links in the footer are present as placeholders and can be connected to real policy pages later.
